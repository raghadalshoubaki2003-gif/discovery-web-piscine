# Discovery Web Piscine

## Project Overview

This project is an introduction to Linux, Git, and GitHub. It helps me learn basic terminal commands, file management, version control, and how to work with repositories on GitHub.

## What I Learned

In this project, I learned how to navigate through directories using the Linux terminal, create and manage files, and use Git to track changes. I also learned how to create a GitHub repository, connect it to my local repository, and push my work to GitHub.

## Why Git Makes Development Easier

Git makes development easier because it keeps track of changes made to a project. It allows me to save different versions of my work using commits and check what was changed and when.

Git is also useful when working with other people because each developer can work on the project, track their changes, and collaborate with the rest of the team.

## Git Workflow

My basic Git workflow is:

working files → git add → git commit → git push

I first make or edit my files, then use git add to prepare the changes, git commit to save them in the Git history, and git push to upload the commits to GitHub.
