Git Workflow

1. Edit
I created and edited the README.md file and added the project documentation.

2. Add
I used "git add README.md" to add the changes to the staging area.

3. Commit
I used "git commit -m "Add project README"" to save the changes in the Git history.

4. Push
I used "git push" to upload the committed changes to the remote GitHub repository.

The basic workflow is:

Edit → git add → git commit → git push
